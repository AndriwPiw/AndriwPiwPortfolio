Small project that started as a small exercise in a more minimalistic poster style and composition, some evocative movies were suggested by a few peers.

A limited time and colour palette had to be used, as well as a restricted typography, in this case, using Satoshi, by Indian Type Foundry. The results are these 10 posters.
